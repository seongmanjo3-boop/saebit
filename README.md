# 새빛 홈페이지 소스 코드

사회단체 새빛의 공식 홈페이지 코드입니다. 별도 서버 프로그램 없이 **HTML 파일 하나 + Supabase(데이터베이스)** 로 동작합니다.

## 들어 있는 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 홈페이지 전체 (화면, 디자인, 기능 코드, 로고 이미지가 모두 이 파일 하나에 들어 있음) |
| `saebit_setup.sql` | Supabase 데이터베이스 설정 (표, 보안 규칙, 파일 저장소, 알림·관리 기록 등 기능 함수) |
| `og-image.png` | 카카오톡·인스타 등에 링크를 올릴 때 뜨는 미리보기 이미지 (1200×630) |
| `robots.txt`, `sitemap.xml` | 네이버·구글 검색 등록용 파일 |
| `email/` | 한국어 메일 양식 (비밀번호 재설정, 회원가입 확인) — Supabase 대시보드에 붙여 넣어 사용 |
| `logo/` | 로고 원본 이미지 (자주색, 흰색 / 배경 투명 PNG) |
| `README.md` | 이 설명서 |

## 바로 열어 보기 (미리보기 모드)

`index.html`을 크롬 같은 브라우저로 열면 바로 동작합니다.
Supabase 연결 정보가 비어 있으면 **미리보기(데모) 모드**로 실행되며, 가입·글쓰기 등 모든 데이터가 그 브라우저에만 저장됩니다.
처음 가입한 계정이 관리자가 되므로 관리자 기능도 시험해 볼 수 있습니다.

## 실제 서비스로 운영하기

1. **Supabase 프로젝트 만들기** — supabase.com 가입 → New project (Region: Seoul)
2. **데이터베이스 설정** — SQL Editor에 `saebit_setup.sql` 전체를 붙여넣고 Run
   (이전 버전을 이미 실행했어도 다시 실행하면 됩니다. 기존 데이터는 유지됩니다)
3. **메일 인증 끄기(권장)** — Authentication → Sign In / Providers → Email → Confirm email 끄기
4. **연결 정보 넣기** — Project Settings → API의 Project URL과 anon public 키를
   `index.html` 아래쪽 `CONFIG`의 `SUPABASE_URL`, `SUPABASE_ANON_KEY`에 입력
5. **올리기** — netlify.com → Add new site → Deploy manually → 이 폴더(`index.html`, `og-image.png`, `robots.txt`, `sitemap.xml`)를 끌어다 놓기
6. **관리자 지정** — 사이트에서 회원가입한 뒤 SQL Editor에서 실행
   `update public.profiles set is_admin = true where username = '아이디';`
7. **도메인 연결** — Netlify Domain management에서 도메인 추가 →
   Supabase Authentication → URL Configuration의 Site URL·Redirect URLs에 같은 도메인 입력
8. **도메인 주소 바꾸기** — `index.html`, `robots.txt`, `sitemap.xml` 안의 `https://saebit.example` 을 실제 주소(예: `https://www.새도메인.kr`)로 모두 바꾼 뒤 다시 올리기.
   이래야 카카오톡 링크 미리보기 이미지가 뜹니다. (카카오톡은 미리보기를 한동안 저장하므로, 바꾼 뒤에는 카카오 개발자 사이트의 '공유 디버거'에서 초기화)
9. **검색 등록** — 네이버 서치어드바이저(searchadvisor.naver.com)와 구글 서치콘솔에 사이트를 등록하고 `sitemap.xml` 주소를 제출
10. **메일을 한국어로 바꾸기 (꼭 한 번 해 주세요)** — Supabase가 보내는 메일은 기본이 영어입니다. 사이트 코드로는 바꿀 수 없고, 대시보드에 한 번 붙여 넣으면 이후 모든 메일이 한국어로 갑니다.
    - Authentication → Email Templates → **Reset Password**
      - Subject: `[새빛] 비밀번호 재설정 안내`
      - Message body: `email/reset_password.html` 파일 내용을 통째로 복사해 붙여 넣고 Save
    - (메일 인증을 켤 경우) **Confirm signup**
      - Subject: `[새빛] 회원가입 이메일 확인`
      - Message body: `email/confirm_signup.html` 내용
    - **메일 발송 계정 연결 (필수)** — Supabase 기본 메일은 **프로젝트 팀원 주소로만, 시간당 2통까지** 보냅니다. 연결하지 않으면 일반 회원은 비밀번호 재설정 메일을 받지 못합니다.
      1. 보낼 Gmail 계정에서 2단계 인증을 켜고, Google 계정 → 보안 → ‘앱 비밀번호’에서 16자리 비밀번호를 만듭니다
      2. Supabase → Authentication → Emails → SMTP Settings → Enable Custom SMTP
      3. Sender email: 그 Gmail 주소 / Sender name: `새빛` / Host: `smtp.gmail.com` / Port: `465` / Username: 그 Gmail 주소 / Password: 앱 비밀번호 → Save
      4. Authentication → Rate Limits에서 시간당 메일 수를 필요한 만큼(예: 30) 올립니다
    - 재설정 링크가 사이트로 돌아오려면 7번의 Site URL·Redirect URLs에 실제 도메인이 들어가 있어야 합니다. 링크는 1시간 동안 한 번만 쓸 수 있습니다.

## 설정값 (`index.html`의 `CONFIG`)

```js
var CONFIG = {
  SUPABASE_URL: '',        // Supabase 프로젝트 주소
  SUPABASE_ANON_KEY: '',   // anon public 키 (공개돼도 되는 키)
  BANK_INFO: '...',        // 후원 계좌
  INSTAGRAM: '...',        // 인스타그램 아이디 (@ 없이)
  EMAIL: '...'             // 대표 이메일
};
```

> ⚠️ Supabase의 **service_role 키는 절대 코드에 넣거나 다른 사람에게 보내지 마세요.** 모든 보안 규칙을 무시할 수 있는 관리자 키입니다. 코드에는 anon 키만 씁니다.

## 기능 목록

- **회원**: 이름·아이디·이메일 가입(중복 확인, 약관·개인정보 동의), 아이디 로그인, 비밀번호 찾기, 마이페이지, 승인제 회원 탈퇴
- **등급**: 일반회원 · 책임회원 · 이사 · 대표이사 · 이사회 의장 (대표이사와 이사회 의장만 겸직)
- **업무 권한**(관리자가 부여): 공지사항 작성, 성명·논평 작성, 연구보고서 올리기, 재정공개 자료 올리기, 행사·교육 관리, 후원 승인, 자유게시판 관리, 책임회원 게시판 관리, 회원 탈퇴 승인, 소식지 구독자 관리
- **글 작성 규칙**: 권한을 받으면 각 게시판(공지사항·성명·논평·연구보고서·재정공개·행사·교육)에 ‘작성하기’ 버튼이 생기고 그 자리에서 씁니다. 관리 화면에서는 쓰지 않습니다.
  - 수정: 누구나 자기가 쓴 글만 (관리자도 남의 글은 수정할 수 없음 — 자유게시판 등 회원 게시판도 같음)
  - 삭제: 관리자만 바로 삭제. 권한자는 자기 글에 ‘삭제 요청’ → 관리자가 관리 화면 ‘게시물 관리’에서 승인(삭제)·반려
  - 이 규칙은 화면뿐 아니라 데이터베이스 보안 규칙으로도 막혀 있습니다
- **후원**: 금액 + 이체 확인 사진/파일로 승인 요청 → 승인·거절, 후원회원 자동 판정(매달 1,000원 이상 3개월 또는 한 번 3,000원 이상). 이체 확인 사진은 처리 후 1년이 지나면 관리 화면에서 삭제 안내
- **새빛 소식**: 공지사항, 성명·논평, 연구보고서, 행사·교육(신청·정원·마감·명단 내려받기), 자유게시판(아이디 표시), 책임회원 게시판, 이사회 게시판(안건·회의록·의결·자료) — 댓글·사진 첨부, 목록 페이지 나누기
- **게시판 관리**: 글·댓글 신고 → 담당자 처리, 도배 방지(글 30초·댓글 10초 간격, 시간당 제한)
- **알림** (화면 위 종 모양, 새 알림은 화면 아래에 잠깐 표시)
  - 모든 회원: 새 공지사항·성명·논평·연구보고서·행사·교육(재정공개는 볼 수 있는 회원만), 내 글에 달린 댓글, 내 후원 승인·거절, 내 등급·권한 변경, 내 신고 처리 결과, 내 삭제 요청 결과
  - 권한자: 후원 요청(후원 승인), 탈퇴 신청(탈퇴 승인), 신고(게시판 관리), 소식지 구독·취소(소식지 관리), 내가 올린 행사의 신청·취소
  - 관리자: 위의 모든 업무 알림 + 삭제 요청 + 회원 등급·권한 변경
- **관리 기록·백업**: 등급·권한 변경, 후원 처리, 탈퇴 처리, 게시물 삭제, 신고 처리 등을 자동 기록(관리자만 열람), 전체 데이터 JSON·회원 명단 CSV 내려받기
- **방문 통계**: 날짜별 방문 수(개인 정보 저장 없음), 최근 30일 그래프
- **소식지**: 홈페이지 맨 아래에서 이메일 구독·취소, 관리 화면에서 주소 복사(숨은참조로 발송)·명단 내려받기
- **페이지**: 설립취지와 회칙, 대표이사 인사말(대표이사만 수정), BI·CI, 자주 묻는 질문, 이용약관, 개인정보처리방침

## 운영 메모

- **백업**: Supabase 무료 플랜은 자동 백업이 없습니다. 관리자 화면 → 관리 기록·백업 → ‘전체 데이터 (JSON)’를 한 달에 한 번쯤 내려받아 보관하세요.
- **소식지 발송**: 사이트가 메일을 직접 보내지는 않습니다. 관리 화면에서 주소를 복사해 Gmail 등의 ‘숨은참조(BCC)’에 붙여 넣어 보내세요.
- **알림**: 사이트 안에서만 뜹니다(이메일·카카오톡 알림 아님). 로그인해 있으면 1분마다 새 알림을 확인합니다.
- Supabase 무료 플랜은 일주일간 접속이 없으면 프로젝트가 일시정지됩니다(대시보드에서 다시 켤 수 있음).
- 메일 발송 계정(SMTP)을 연결하지 않으면 비밀번호 재설정 메일이 회원에게 가지 않습니다(10번 참고). Gmail은 하루 약 500통까지 보낼 수 있습니다.

## 코드 구조 (`index.html`)

1. `<style>` — 디자인. 맨 위 `:root`에 색상·서체 값이 모여 있고 다크 모드 값도 함께 정의
2. HTML — 메인 화면(`#home`)과 각 화면(`#v-signup`, `#v-board`, `#v-events`, `#v-admin` 등). 주소 뒤 `#이름`으로 화면 전환
3. `<script>` —
   - `CONFIG` : 설정값
   - `Demo` : 미리보기 모드용 저장 기능(브라우저 저장소)
   - `Live` : 실제 서비스용 Supabase 연동 기능
   - 그 아래 : 화면별 동작(회원가입, 후원, 게시판, 행사, 알림, 관리자 등)

보안(누가 무엇을 보고 쓸 수 있는지)은 화면 코드가 아니라 `saebit_setup.sql`의 보안 규칙(RLS)에서 지켜집니다. 화면 코드를 바꿔도 권한 없는 사람이 데이터를 볼 수는 없습니다.
